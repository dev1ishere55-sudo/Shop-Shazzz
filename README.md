# Shop Shazzz

**Curated retail. For the cool kids.**

Premium e-commerce site + Telegram Mini App for Shop Shazzz (Nigeria — Keffi / Abuja / Kaduna / Jos).

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:3000

## What’s included

- Home with 3 entry paths: **In Stock** · **Curated Finds** · **Suya Sunny**
- Shop filters, product detail, cart, checkout (Naira + delivery zones)
- Telegram Mini App support (SDK, BackButton, MainButton, user prefill)
- Brand UI: navy `#1B2A56`, plum `#5B4B63`, ivory `#FBF9F4`

See **BUILD_PLAN.md** for the phased path to production (Supabase → Paystack → Bot).

## Deploy

Push to this repo → import on [Vercel](https://vercel.com) → done.
